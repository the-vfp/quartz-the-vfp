# Honored Drinks

## Description

A bar. I've never set foot in it. All I have is the name off the back of a jacket on camera.

## Notes

It was one of three open leads early on — Honored Drinks, the [[Darkhour Office]], and [[verumtenebris.org]]. We went after Darkhour. This one we never touched.

[[Steve Jensen]], the man whose jacket carried the branding, is dead. The bar itself is still a thread no one has pulled.
