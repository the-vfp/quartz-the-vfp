# Plant Tracker 

**Plant Tracker** is a personal app that I built using Claude to manage the watering schedule and make a care log for all of my house plants.

You can use the actual app —  it works on both web and mobile and I've prepopulated it with demo plants so you can get a feel for how it actually flows. I've also built a help center to demonstrate how I approach knowledge base design. The *Product Journey* walks through my process for building the app and the help center.
